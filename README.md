# 📐 피타고라스 조각 퍼즐

직각삼각형의 두 변 위 정사각형(a², b²) 조각들을 옮겨 빗변 위의 큰 정사각형(c²)을 빈틈없이 채우며 **a² + b² = c²** 를 확인하는 수업용 퍼즐입니다.

▶ 바로 하기: https://kanghy3046.github.io/pythagoras-puzzle/

- 5단계 (이등변 4조각 → 페리갈 5조각 → 8-15-17 8조각)
- 도전 모드: 1~5단계 연속 스톱워치 기록, 기기별 순위 (힌트 1번당 +10초, 힌트는 30초마다 1번)
- 단계별 연습 모드
- 돌리기(90°) · 뒤집기 버튼, 두 번 톡하면 회전, 자석처럼 붙는 맞춤, 효과음
- 휴대폰 터치 최적화, 설치 없이 `index.html` 한 파일로 동작
